# 共享素材库（可选）

本目录用于放置**团队/项目级共享参考材料**（如行业术语表、公司介绍、岗位能力模型等纯参考资料）。

- 服务启动时会扫描本目录下的文本/Word/PDF 文件，作为可选的"背景知识"提供给改写模型；
- 这是**可选功能**：目录为空或不创建本目录时，服务完全正常运行，仅基于用户上传的简历与 JD 进行改写；
- 请勿在此放入任何包含个人隐私的文件（真实简历、身份证号、联系方式等）；
- 本目录内容默认**不会**被提交到 Git（如需要纳入版本管理，请自行调整 `.gitignore`）。

放入参考材料后，模型会在"联网检索并改写"等场景里参考其中的内容，让生成的简历更贴合特定行业语境。
